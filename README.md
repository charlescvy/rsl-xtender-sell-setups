# RSL-Xtender Sell Setups

**🇬🇧 English** | [🇫🇷 Français ↓](#-français)

Ready-to-import **auto-sell profiles** for [RSL-Xtender](https://rsl-x.gg/xtender/) (Raid: Shadow Legends companion app). Stop sorting gear — spend your play time playing.

## Which profile do I need?

| Profile | Dungeons | Clan Boss | Status |
|---|---|---|---|
| **[Early](early/)** | ~10-15 (Dragon 13 pivot) | Easy / Normal / Hard | 🧪 **available — early-v1** (field-testing) |
| **[Mid](mid/)** | 16-22 on auto | Brutal / Nightmare | ✅ **available — midgame-v3** |
| **[Late](late/)** | 24-25 | Ultra-Nightmare 2 keys | 🧪 **beta — late-v1-beta** (testers wanted) |
| **End** | 25 speed-farm | UNM 1 key | 🔜 planned |

Progression is rarely uniform — **pick by the dungeon column first**: dungeons determine what drops, hence what needs sorting.

## How to install

1. Download the `.json` from the profile folder (e.g. [`mid/midgame-v3.json`](mid/midgame-v3.json))
2. In RSL-Xtender: **Sell** tab → import icon (top right) → select the JSON
3. ⚠️ This **replaces** your current configuration — export it first if you want a backup

Each profile folder has a full explanation of its rules in English (`README.md`) and French (`README.fr.md`).

See the [roadmap](ROADMAP.md) for what's coming.

# 🇫🇷 Français

Des **profils d'auto-vente prêts à importer** pour [RSL-Xtender](https://rsl-x.gg/xtender/) (application compagnon de Raid: Shadow Legends). Parce que ton temps de jeu, c'est pour jouer, pas pour ranger !

## Quel profil pour moi ?

| Profil | Donjons | Clan Boss | Statut |
|---|---|---|---|
| **[Early](early/)** | ~10-15 (pivot Dragon 13) | Easy / Normal / Hard | 🧪 **disponible — early-v1** (en test terrain) |
| **[Mid](mid/)** | 16-22 en auto | Brutal / Nightmare | ✅ **disponible — midgame-v3** |
| **[Late](late/)** | 24-25 | Ultra-Nightmare 2 clés | 🧪 **bêta — late-v1-beta** (testeurs recherchés) |
| **End** | 25 speed-farm | UNM 1 clé | 🔜 prévu |

La progression n'est jamais uniforme — **choisissez d'abord selon la colonne donjons** : ce sont eux qui déterminent ce qui droppe, donc ce qu'il faut trier.

## Installation

1. Téléchargez le `.json` dans le dossier du profil (ex. [`mid/midgame-v3.json`](mid/midgame-v3.json))
2. Dans RSL-Xtender : onglet **Sell** → icône d'import (en haut à droite) → sélectionner le JSON
3. ⚠️ L'import **remplace** votre configuration actuelle — exportez-la d'abord si vous voulez une sauvegarde

Chaque dossier de profil contient l'explication complète de ses règles en français (`README.fr.md`) et en anglais (`README.md`).
